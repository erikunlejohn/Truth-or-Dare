# Truth or Dare — Simple 2-Player Version

This version intentionally removes the complex multi-game architecture.

## Flow

Home
→ Enter 2 Players
→ Choose Truth or Dare
→ Truth: Tell the Truth or Drink
→ Dare: Do the Dare or Drink
→ Next Player
→ Repeat

## Files

- index.html
- style.css
- script.js

## Important

The provided Dare questions have been placed in `script.js` exactly as supplied. Replace the sample `truthQuestions` array with your own Truth questions.

Open `index.html` in a modern browser to run it.
